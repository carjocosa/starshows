# Starshows — Productora de Conciertos (Self-Hosted)

**Stack:** Next.js 15 (Poppins) + NestJS + Prisma + Postgres + Redis + Directus 11 + MinIO + Caddy

Ver `DEPLOY.md` para deploy en VPS y `AUDIT.md` para auditoría completa.

- Prototipo validado: `../starshows-ecosystem/prototype/index.html` (http://localhost:3032)
- Admin previews: http://localhost:3033/admin-full.html y admin-system.html y admin-permisos.html

## Deploy rápido
```bash
cp .env.example .env && ./deploy.sh
```
